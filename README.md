# 🦋 Butterfly Blog Website

A simple and elegant blog website to explore fascinating information about butterflies. Built with **Node.js**, **Express.js**, and **EJS** templating engine.

---

## 🌟 Features

- 🏠 Home page with featured butterflies
- 📄 Informative blog pages on different butterfly species
- 📚 About page introducing the blog
- 📬 Contact page for inquiries
- ✨ Clean layout using EJS and static assets (CSS/images)
